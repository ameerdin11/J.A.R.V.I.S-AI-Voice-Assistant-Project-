# J.A.R.V.I.S-AI-Voice-Assistant-Project-
Jarvis is an AI voice assistant for PC and smart home control. It features noise-reduced mic capture, local Whisper speech-to-text, Hinglish intent parsing, and online/offline brains (OpenAI/Ollama). Built with a glassmorphic Flask web dashboard, it handles physical GPIO pins/PC automation, session memory, and text-to-speech output.
